Mnemosyne

Politica de Privacidade

Ultima atualizacao: 13 de maio de 2026

1. Quem somos

Esta Politica de Privacidade explica como o Mnemosyne trata dados no site, na app web e na app Android publicada com o package com.mnemosyne.mobile. O Mnemosyne e uma ferramenta de memoria, notas, pesquisa assistida por IA e visualizacao de conhecimento pessoal.

Contacto para privacidade e suporte: suporte@mnemosyne.app.

2. Dados que podemos recolher

  • Dados de conta, como email, identificador de utilizador e metodo de autenticacao.
  • Conteudo criado pelo utilizador, como memorias, notas, etiquetas, anexos e relacoes entre ideias.
  • Chaves publicas e metadados tecnicos necessarios para funcionalidades de Comms, partilha e sincronizacao.
  • Pedidos de pesquisa web ou comandos de IA quando o utilizador decide usar essas funcionalidades.
  • Dados tecnicos minimos, como registos de erro, eventos de seguranca e informacao necessaria para manter o servico.
  • Dados de pagamento apenas quando planos pagos forem ativados; neste caso, o processamento sera feito por fornecedor de pagamentos externo.

3. Permissoes do dispositivo

A app Android pode pedir acesso a camera para ler QR codes de emparelhamento ou instalacao. O Mnemosyne nao usa esta permissao para gravar fotografias pessoais sem acao do utilizador.

4. Como usamos os dados

  • Criar e proteger a conta do utilizador.
  • Guardar, sincronizar, pesquisar, editar e apresentar memorias.
  • Gerar visualizacoes, clusters, relacoes semanticas e insights pessoais.
  • Permitir Comms, partilhas e emparelhamento entre dispositivos quando ativado pelo utilizador.
  • Executar pedidos de pesquisa web ou IA quando o utilizador solicitar.
  • Prevenir abuso, diagnosticar falhas e manter a seguranca do servico.

5. IA, pesquisa web e fornecedores externos

O Mnemosyne privilegia processamento local e controlado pelo utilizador. Quando uma funcionalidade exige um fornecedor externo, como Firebase, Google Cloud, Stripe ou um fornecedor de IA configurado pelo utilizador, apenas os dados necessarios para executar a funcionalidade sao enviados.

As memorias do utilizador nao sao vendidas e nao sao usadas pelo Mnemosyne para treinar modelos publicos. Provedores externos podem ter as suas proprias politicas quando o utilizador decide usar esses servicos.

6. Partilha de dados

Nao vendemos dados pessoais. Podemos partilhar dados apenas com fornecedores essenciais para operar o servico, cumprir obrigacoes legais, proteger utilizadores ou executar uma acao pedida pelo proprio utilizador.

  • Firebase/Google Cloud para autenticacao, base de dados, armazenamento, funcoes e hosting.
  • Stripe ou fornecedor equivalente para pagamentos, quando planos pagos estiverem ativos.
  • Fornecedores de IA ou pesquisa apenas quando a funcionalidade for usada ou configurada pelo utilizador.

7. Seguranca

Aplicamos controlos tecnicos para reduzir risco de acesso nao autorizado, incluindo HTTPS, regras de seguranca, autenticacao, armazenamento protegido no dispositivo e separacao entre chaves privadas e dados publicos sempre que aplicavel. Nenhum sistema e totalmente imune a falhas, mas trabalhamos para proteger os dados de forma proporcional ao risco.

8. Retencao e eliminacao

Mantemos dados enquanto a conta existir ou enquanto forem necessarios para fornecer o servico, cumprir obrigacoes legais ou resolver problemas de seguranca. O utilizador pode eliminar memorias dentro da app e pode pedir ou iniciar eliminacao da conta nas definicoes quando essa opcao estiver disponivel.

Para pedir eliminacao de conta ou dados, contacte suporte@mnemosyne.app ou use a pagina publica de eliminacao de conta. O pedido deve incluir o email da conta para conseguirmos localizar os dados.

9. Criancas

O Mnemosyne nao e dirigido a criancas com menos de 13 anos. Se descobrirmos que recolhemos dados de uma crianca sem consentimento adequado, tomaremos medidas razoaveis para eliminar esses dados.

10. Direitos do utilizador

Dependendo da legislacao aplicavel, o utilizador pode pedir acesso, correcao, exportacao, oposicao ou eliminacao dos seus dados pessoais. Para exercer estes direitos, contacte o suporte indicado nesta politica.

11. Alteracoes a esta politica

Podemos atualizar esta politica para refletir alteracoes no produto, requisitos legais ou praticas de seguranca. A data no topo desta pagina indica a versao mais recente.
