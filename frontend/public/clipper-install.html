Instalar o Clipper

Extensão Chrome/Edge (Manifest V3). Envia título, URL e seleção para esta web app. A cifra E2EE só acontece depois de desbloqueares a sessão — a extensão não tem a mnemónica.

Carregar unpacked

  1. Abre chrome://extensions (ou edge://extensions).
  2. Liga Developer mode / modo de programador.
  3. Load unpacked e escolhe a pasta frontend/extensions/clipper/ do repositório Mnemosyne.
  4. Clica no ícone da extensão, revê o recorte e envia. Precisas de sessão desbloqueada em https://mnemosyne-one.web.app.

Limitações

  • Query máxima ~1.5 KB — textos longos são truncados.
  • Páginas chrome:// e PDFs nativos podem não expor a seleção.
  • O atalho desktop Ctrl+Shift+M é da app Tauri, não da extensão.
