---

## PARTE I: POSICIONAMENTO DE CATEGORIA

### O Mnemosyne NÃO é:

- ❌ Um PKM (Personal Knowledge Management)
- ❌ Um grafo de conhecimento
- ❌ Um workspace colaborativo
- ❌ Um chat com IA
- ❌ Uma aplicação

### O Mnemosyne É:

> **Um Cognitive Universe Engine — um ambiente cognitivo privado, navegável e vivo, onde pensamento, memória, identidade e colaboração existem como um universo inteligente.**

Cada utilizador não abre uma aplicação. **Entra no seu próprio universo mental.**

## PARTE II: A EXPERIÊNCIA FUNDAMENTAL

### Entrada no Sistema

Quando o utilizador abre o Mnemosyne:

1. **Não há dashboard**
2. **Não há lista de documentos**
3. **Não há menu tradicional**

O que existe:

- **Um universo espacial vivo**
- **Profundidade infinita**
- **Objetos celestes flutuando**
- **Movimento contínuo e orgânico**
- **Sensação imediata de inteligência**

A interface sussurra:

> "A interpretar o teu pensamento…"  
> "A ligar ideias antigas…"  
> "A encontrar padrões…"

### Navegação Espacial

Inspirada no **Celestia**, mas não é uma simulação astronómica:

- **Zoom progressivo** — de visão galáctica até detalhe atómico
- **Rotação fluida** — exploração em 360° sem fricção
- **Clique para selecionar** — qualquer objeto pode ser alcançado
- **Gravidade semântica** — objetos relacionados orbitam-se mutuamente
- **Profundidade real** — não é 2D disfarçado de 3D

### Criação de Memória

Não há "Nova Nota". Há **manifestação de pensamento**:

1. **Input livre** — texto, voz, arrastar ficheiro
2. **Processamento cognitivo** — sistema interpreta intenção
3. **Geração automática de nós** — memória torna-se objeto celeste
4. **Ligação em tempo real** — conexões formam-se instantaneamente
5. **Posicionamento inteligente** — objeto aparece onde faz sentido

O sistema nunca pergunta:

- "Onde guardar?"
- "Que tags usar?"
- "Que categoria?"

O sistema **sabe**.

## PARTE III: MODELO COGNITIVO-ESPACIAL

### Taxonomia de Objetos Celestes

Cada tipo de memória tem uma representação física e comportamento único:

#### 1. ESTRELA (Memória Simples)

**O que é:**
- Pensamento individual
- Nota isolada
- Ideia única

**Comportamento:**
- Brilho proporcional à relevância
- Cor baseada em categoria semântica
- Pulsa quando recentemente acessada
- Atrai memórias relacionadas

**Física:**
- Massa baixa
- Gravidade fraca
- Movimento livre

---

#### 2. SOL (Memória Central)

**O que é:**
- Conceito fundamental
- Ideia que organiza outras
- Núcleo de pensamento

**Comportamento:**
- Irradia luz para memórias dependentes
- Cria sistema orbital
- Influencia grande área do universo
- Nunca se move (ponto fixo)

**Física:**
- Massa alta
- Gravidade forte
- Atração de múltiplos objetos

---

#### 3. PLANETA (Subideia)

**O que é:**
- Desenvolvimento de conceito central
- Aplicação de ideia principal
- Variação de tema

**Comportamento:**
- Orbita um Sol
- Pode ter luas próprias
- Rotação própria
- Pode ter atmosfera (contexto)

**Física:**
- Massa média
- Órbita estável
- Gravidade moderada

---

#### 4. LUA (Detalhe)

**O que é:**
- Nota de suporte
- Exemplo específico
- Referência
- Citação

**Comportamento:**
- Orbita um Planeta
- Movimento rápido
- Sempre visível quando planeta está próximo
- Pode colidir e fundir-se

**Física:**
- Massa baixa
- Órbita rápida
- Gravidade mínima

---

#### 5. COMETA (Insight)

**O que é:**
- Ideia súbita
- Conexão inesperada
- Momento "eureka"

**Comportamento:**
- Atravessa o universo em trajetória única
- Deixa rastro luminoso
- Conecta áreas distantes
- Aparece e desaparece

**Física:**
- Trajetória elíptica extrema
- Velocidade alta
- Sem órbita fixa

---

#### 6. BURACO NEGRO (Contradição)

**O que é:**
- Ideia que contradiz outras
- Conflito cognitivo
- Paradoxo não resolvido

**Comportamento:**
- Distorce espaço ao redor
- Atrai memórias relacionadas
- Cria tensão visual
- Pode "engolir" ideias fracas

**Física:**
- Gravidade extrema
- Distorção espacial
- Horizonte de eventos visível

---

#### 7. NEBULOSA (Cluster de Ideias)

**O que é:**
- Grupo de pensamentos relacionados
- Área de exploração ativa
- Conceito em formação

**Comportamento:**
- Nuvem de partículas
- Movimento interno constante
- Pode colapsar em Sol
- Pode dispersar-se

**Física:**
- Densidade variável
- Sem forma definida
- Evolução contínua

---

#### 8. CONSTELAÇÃO (Padrão Semântico)

**O que é:**
- Estrutura de pensamento
- Relação entre conceitos distantes
- Narrativa emergente

**Comportamento:**
- Linhas conectam estrelas específicas
- Visível apenas em certos ângulos
- Pode ser nomeada pelo utilizador
- Revela-se progressivamente

**Física:**
- Não tem massa própria
- Estrutura emergente
- Dependente de perspetiva

---

#### 9. MATÉRIA ESCURA (Memória Esquecida)

**O que é:**
- Conhecimento não acessado há muito tempo
- Ideia abandonada
- Pensamento em hibernação

**Comportamento:**
- Invisível mas presente
- Influencia gravitacionalmente
- Pode ser reativada
- Revela-se com busca específica

**Física:**
- Massa presente
- Sem emissão de luz
- Gravidade ativa

---

#### 10. QUASAR (Produção Intensa)

**O que é:**
- Período de criatividade extrema
- Explosão de ideias
- Fase de trabalho intenso

**Comportamento:**
- Emissão de energia massiva
- Cria múltiplas memórias rapidamente
- Ilumina área vasta
- Temporário mas impactante

**Física:**
- Energia extrema
- Radiação em todas direções
- Instável

---

### Dinâmicas Físicas

#### Gravidade Semântica

Objetos atraem-se baseado em:

- **Similaridade semântica** (embeddings)
- **Frequência de co-acesso**
- **Relações explícitas**
- **Contexto temporal**

#### Colisões e Fusões

Quando dois objetos se aproximam demais:

- **Fusão** — criam novo objeto maior
- **Órbita** — um orbita o outro
- **Repulsão** — se contraditórios
- **Ressonância** — sincronização de movimento

#### Decaimento Temporal

Memórias não acessadas:

- **Perdem brilho** progressivamente
- **Afastam-se** do centro
- **Tornam-se matéria escura**
- **Mantêm gravidade** (podem ser recuperadas)

### 1. COGNITIVE ENGINE

**Responsabilidades:**

- Processamento de linguagem natural
- Geração de embeddings
- Detecção de padrões
- Identificação de contradições
- Sugestões inteligentes
- Classificação automática

**Tecnologias:**

- **LLM local** (Llama, Mistral)
- **Embeddings** (sentence-transformers)
- **Vector DB** (Qdrant, Milvus)
- **Graph DB** (Neo4j, NetworkX)

**Operações:**

```python
class CognitiveEngine:
    def process_memory(self, content: str) -> Memory:
        # 1. Gerar embedding
        embedding = self.embed(content)
        
        # 2. Classificar tipo
        memory_type = self.classify_type(content, embedding)
        
        # 3. Encontrar relações
        relations = self.find_relations(embedding)
        
        # 4. Detectar contradições
        conflicts = self.detect_conflicts(content, relations)
        
        # 5. Determinar posição espacial
        position = self.calculate_position(embedding, relations)
        
        # 6. Criar objeto celeste
        celestial_object = self.create_object(
            memory_type, 
            position, 
            relations, 
            conflicts
        )
        
        return Memory(
            content=content,
            embedding=embedding,
            type=memory_type,
            celestial_object=celestial_object,
            relations=relations,
            conflicts=conflicts
        )
```

class SpatialNavigator {
  constructor() {
    this.camera = {
      position: [0, 0, 1000],
      target: [0, 0, 0],
      up: [0, 1, 0],
      fov: 45,
      near: 0.1,
      far: 100000
    };
    
    this.physics = {
      velocity: [0, 0, 0],
      angularVelocity: [0, 0, 0],
      damping: 0.95,
      gravity: true
    };
  }
  
  // Zoom suave até objeto
  zoomTo(target, duration = 1000) {
    const start = this.camera.position;
    const end = this.calculateOptimalPosition(target);
    
    this.animate(start, end, duration, (pos) => {
      this.camera.position = pos;
      this.render();
    });
  }
  
  // Rotação com inércia
  rotate(deltaX, deltaY) {
    this.physics.angularVelocity[0] += deltaY * 0.01;
    this.physics.angularVelocity[1] += deltaX * 0.01;
  }
  
  // Update loop
  update(deltaTime) {
    // Aplicar velocidade
    this.camera.position[0] += this.physics.velocity[0] * deltaTime;
    this.camera.position[1] += this.physics.velocity[1] * deltaTime;
    this.camera.position[2] += this.physics.velocity[2] * deltaTime;
    
    // Aplicar rotação
    this.applyRotation(this.physics.angularVelocity, deltaTime);
    
    // Aplicar damping
    this.physics.velocity = this.physics.velocity.map(v => v * this.physics.damping);
    this.physics.angularVelocity = this.physics.angularVelocity.map(v => v * this.physics.damping);
    
    // Gravidade semântica
    if (this.physics.gravity) {
      this.applySemanticGravity();
    }
  }
  
  // Gravidade baseada em relações
  applySemanticGravity() {
    const nearbyObjects = this.findNearbyObjects(this.camera.position, 500);
    
    nearbyObjects.forEach(obj => {
      const distance = this.distance(this.camera.position, obj.position);
      const force = (obj.mass * 100) / (distance * distance);
      const direction = this.normalize(
        this.subtract(obj.position, this.camera.position)
      );
      
      this.physics.velocity[0] += direction[0] * force;
      this.physics.velocity[1] += direction[1] * force;
      this.physics.velocity[2] += direction[2] * force;
    });
  }
}
